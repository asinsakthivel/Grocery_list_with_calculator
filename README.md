# 🛒 Grocery List & Calculator

A **JavaScript-based web app** to manage grocery expenses. Users can add items with a name, price, and quantity, and the app automatically calculates the total cost. It also tracks spending against a set budget and highlights overspending in **red**.

---

## 🚀 Features
- Add items with name, price, and quantity  
- Auto-calculates total cost  
- Budget tracking with balance display  
- Overspending alert (red text)  
- Clear list and responsive design  

---

## 🧠 Tech Stack
**HTML**, **CSS**, **JavaScript (ES6)**

---

## ⚙️ How to Use
1. Enter item details and click **Add Item**  
2. Set a **budget** amount  
3. View total and remaining balance instantly  
4. Clear list anytime to start over
